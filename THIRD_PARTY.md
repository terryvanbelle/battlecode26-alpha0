# Third-party material

The official Battlecode 2026 engine and client project are GPL-3.0 licensed; this repository includes local patches, bridge integration and official rules for research. Original engine binaries/source archives are downloaded from the official release host, hash-checked, and kept under ignored `vendor/`. See the upstream [Battlecode 2026 repository](https://github.com/battlecode/battlecode26) and the setup manifest for exact versions.

The map collection and engine-checked rules digest were obtained from `terryvanbelle/battlecode26b-vibe` commit `f4d6ec971b13a20f7f38fb56d249f62c0251ed05`. The original rules text retains its Battlecode authorship. Map provenance and hashes are recorded separately.

External benchmark bots remain the work of their respective authors. The benchmark manifest records each upstream repository, commit, package and file digest. Their source is fetched on setup into ignored directories rather than redistributed in this repository. Upstream license information is recorded where present. See the benchmark documentation for source download and licensing details.
